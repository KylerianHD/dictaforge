# Code of conduct

Be decent. Concretely:

- Critique code and ideas, not people. No harassment, insults, or discrimination of any kind, in any project space.
- Assume good faith, especially across language barriers; many contributors are not native English speakers.
- No spam, no advertising, no derailing.

Maintainers may edit, remove, or reject contributions and comments that break these rules, and ban repeat offenders. To report a problem, contact the maintainer privately via the address on their GitHub profile.

This will be replaced with a fuller document (Contributor Covenant or similar) if the community grows enough to need one.
